# NivionTech Titanium 2.0

Protótipo visual isolado das quatro telas prioritárias do CRM: Dashboard, Pipeline, Cliente 360° e Orbit. Não acessa banco, autenticação ou APIs e não altera dados.

O protótipo preserva funções e fluxos existentes, concentrando-se em hierarquia, composição, tipografia, densidade, paleta, microinterações e adaptação mobile.

## Licenças

Não foram incorporados componentes, ícones ou bibliotecas externas. A marca reutiliza os ativos já existentes no repositório. Ícones são SVGs originais simples; tipografia usa a pilha local do sistema com preferência por Manrope quando disponível.
